# web-iaw

## Descripción
Proyecto web desarrollado para la práctica de aprendizaje de Git y GitHub en el módulo de Implantación de Aplicaciones Web (IAW) de 2.º ASIR.

## Requisitos
- Navegador web moderno (Chrome, Firefox, Edge).
- Git instalado en el equipo local.

## Instalación
Para clonar este repositorio:
`ash
git clone https://github.com/marcelomoralgutierrez/web-iaw.git
`

## Ejecución
Abrir el archivo `index.html` en cualquier navegador web o usando Live Server.
